# Vanilla Entity Reference

This folder documents the JSON schemas of Book of Hours' built-in Fucine
entity types, generated by inspecting the game's decompiled source and content
files.

**Warning: these documents have not been proofread for correctness.** They are
provided as a starting point only. Field names, types, defaults, and behaviour
may be inaccurate, incomplete, or out of date. Verify against the game's
own content or decompiled code before relying on a field in a mod.

Please report any errors you find so they can be corrected.
